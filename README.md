## 01. // ABOUT PROJECT

**SajidX IDE** is a web-based online compiler that allows users to write, compile, and execute C and C++ programs directly from their browser.

Built with a modern web development stack, it provides a clean coding environment with a powerful code editor and an easy-to-use interface.

No local compiler installation is required to use the online compiler.

## 03. // FEATURES

- 💻 **Online Code Editor** – Write C and C++ programs directly in your browser.
- ⚡ **Instant Compilation** – Compile and execute code using Judge0.
- 🔤 **Multiple Languages** – Supports C and C++.
- 📝 **Custom Input** – Provide custom input to your programs.
- 📤 **Output Display** – View program output and compilation errors.
- 🎨 **Light & Dark Theme** – Switch between editor themes.
- 🖥️ **Full-Screen Editor** – Enjoy a distraction-free coding experience.
- 📋 **Copy Code** – Copy your source code with one click.
- 🔄 **Reset Code** – Restore the default code.
- 📱 **Responsive Design** – Use the application across different screen sizes.
- 📊 **Execution Information** – View execution time and memory usage when available.

## 06. // RUN LOCALLY

Follow these steps to run SajidX IDE on your local machine.

**Step 1 — Clone Repository**

```bash
git clone https://github.com/AI-SajidX/SajidX-IDE.git
```

**Step 2 — Navigate to Project**

```bash
cd SajidX-IDE
```

**Step 3 — Install Frontend Dependencies**

```bash
npm install
```

**Step 4 — Start Frontend**

```bash
npm run dev
```

Open your browser:

```text
http://localhost:3000
```

### Backend Setup

Open another terminal:

```bash
cd backend
npm install
node server.js
```

The backend will run on:

```text
http://localhost:5000
```

For local development, configure the frontend API endpoint to use the local backend URL.
